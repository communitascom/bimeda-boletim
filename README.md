# Boletim Bimeda

Previews web do boletim mensal da Bimeda, para aprovação do cliente, e hospedagem pública das imagens usadas na importação para o RD Station.

- `index.html` | landing de aprovação
- `comercial.html` | modelo comercial
- `editorial.html` | modelo editorial
- `outubro.html` | boletim de outubro/2026, opção 1 (sem a vitrine de produtos)
- `outubro-produtos.html` | boletim de outubro/2026, opção 2 (com a vitrine)
- `images/outubro-2026/` | imagens do mês (URL pública, também usada para importar no RD)
- `images/` | imagens (também servem de URL pública para o RD)

Publicado via GitHub Pages. Fonte de verdade dos modelos: `Clientes/Bimeda/Boletim Mensal/modelos/` no vault da Communitas.
